# Лаг Маркет Пауэр

Android-приложение: сравнивает котировку пая ОПИФ «Маркет Пауэр — Акции» с тем, куда ушли бумаги фонда после даты последней стоимости пая, и показывает, есть ли смысл докупать или выходить в рубли.

## Откуда данные

| Что | Откуда | Как часто |
|---|---|---|
| Цены акций топ-10 и индекс МосБиржи | открытый API Мосбиржи (iss.moex.com), задержка ~15 мин | каждые 30 сек – 5 мин |
| Цены закрытия за прошлые дни | история Мосбиржи | раз в 15 мин |
| Стоимость пая и состав топ-10 | сайт УК contrada-capital.ru | раз в 15 мин |
| Котировка «Продают по» | вводится вручную (необязательно) | — |

Без введённой котировки приложение считает её как стоимость пая ± спред (по умолчанию 0,5%).

## Как скачать

Каждый push в ветку `main` собирает APK через GitHub Actions. Готовый файл лежит в разделе **Releases** → последняя «Сборка N» → `MarketPowerLag.apk`. Новые сборки ставятся поверх старой, данные и настройки сохраняются.

## Telegram-бот

`bot/mp_bot.py` запускается через GitHub Actions каждые 10 минут с 07:00 до 00:50 МСК (`.github/workflows/bot.yml`).

| Событие | Что пишет |
|---|---|
| Расчётная стоимость пая выше котировки на 3%+ после спреда | 🟢 ПОКУПАТЬ: расчётная, фактическая, котировка |
| Расчётная ниже на 3%+ | 🔴 ПРОДАВАТЬ |
| Сигнал пропал | ⚪ сигнал больше не действует (повтор действующего сигнала — раз в 3 часа) |
| ~19:00 МСК | 📋 сводка дня (карточка ДЕРЖАТЬ, если сигнала нет) |
| 3 проверки подряд (30 минут) без данных Мосбиржи; сайт УК — больше суток | ⚠️ нет связи; затем ✅ когда восстановится |
| Сообщение «статус» боту | сводка со следующей проверкой |
| «купить по 154,83», «продать по 153,29» | цены из приложения Совкомбанка: бот считает от них и знает реальный спред |
| «сброс» | снова оценивать цены самому |

Настройка: секрет `TELEGRAM_TOKEN` (Settings → Secrets and variables → Actions). Порог, спред и час сводки — переменные `THRESHOLD`, `SPREAD`, `SUMMARY_HOUR` в `bot.yml`. Прислать сводку сразу: Actions → Bot → Run workflow.

## Ограничения

- Сигнал верен, только если цены продержатся до закрытия дня, по которому УК посчитает новую стоимость пая.
- Если сайт УК поменяет вёрстку, приложение попросит ввести стоимость пая вручную.
- Это калькулятор, а не инвестиционная рекомендация.
