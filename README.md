# Лаг Маркет Пауэр

Android-приложение: сравнивает котировку пая ОПИФ «Маркет Пауэр — Акции» с тем, куда ушли бумаги фонда после даты последней стоимости пая, и показывает, есть ли смысл докупать или выходить в рубли.

## Откуда данные

| Что | Откуда | Как часто |
|---|---|---|
| Цены акций топ-10 и индекс МосБиржи | открытый API Мосбиржи (iss.moex.com), задержка ~15 мин | каждые 30 сек – 5 мин |
| Цены закрытия за прошлые дни | история Мосбиржи | раз в 15 мин |
| Стоимость пая и состав топ-10 | сайт УК contrada-capital.ru | раз в 15 мин |
| Котировка «Продают по» | вводится вручную (необязательно) | — |

Без введённой котировки приложение считает её как стоимость пая ± спред (по умолчанию 0,5%).

## Как скачать

Каждый push в ветку `main` собирает APK через GitHub Actions. Готовый файл лежит в разделе **Releases** → последняя «Сборка N» → `MarketPowerLag.apk`. Новые сборки ставятся поверх старой, данные и настройки сохраняются.

## Telegram-бот

`bot/mp_bot.py` запускается через GitHub Actions (`.github/workflows/bot.yml`): каждые 10 минут его вызывает cron-job.org через API (`workflow_dispatch`, `mode=auto`), запасной запуск по расписанию GitHub — раз в час. Вечером (19:00–00:05) каждый запуск сам проверяет каждые 2,5 минуты, поэтому ответ на команды и скриншоты приходит за 2–3 минуты.

**Как работает лаг** (подтверждено сделками 2025 года и ценами банка 02.11.2026): днём Совкомбанк обновляет цену пая вслед за рынком; после закрытия основной сессии (19:00) цена замораживается до утра, а вечерняя сессия (19:00–23:50) продолжает двигать акции. Сигнал — движение акций топ-10 фонда на вечерней сессии относительно закрытия основной (`research/evening.py` — бэктест).

| Событие | Что пишет |
|---|---|
| Вечером выгода от покупки/выхода ≥ порога (1,5%) после спреда | 🟩 ПОКУПАТЬ / 🟥 ПРОДАВАТЬ (ПРЕДВАРИТЕЛЬНО до 23:50, затем ПОДТВЕРЖДЕНО) |
| Сигнал пропал | ⬜ ДЕРЖАТЬ |
| 23:00 МСК | 📋 сводка дня |
| Утро после сделки, банк снова обновляет цену | карточка «закрыть круг» |
| 30 минут без данных Мосбиржи; сайт УК — больше суток | ⚠️ нет связи; затем ✅ |
| Скриншот страницы пая из приложения | бот сам читает «Купить по» и «Продать по» (распознавание текста), как команду «купить по … продать по …» |
| Расчётная цена ушла на 1,5% от последних цен | 🔔 просьба прислать скриншот; повтор — только если ушла ещё на 0,5% дальше или после твоих цен |
| «статус», «купить по … продать по …», «купил/продал N по …», «сделки», «сброс», «помощь» «журнал» (последние сигналы и итог «что было бы»), «помощь» (и по-английски) | см. «помощь» в боте |

Настройка: секрет `TELEGRAM_TOKEN`. Порог, спред и час сводки — переменные `THRESHOLD`, `SPREAD`, `SUMMARY_HOUR` в `bot.yml`.

## Ограничения

- Сигнал верен, только если цены продержатся до закрытия дня, по которому УК посчитает новую стоимость пая.
- Если сайт УК поменяет вёрстку, приложение попросит ввести стоимость пая вручную.
- Это калькулятор, а не инвестиционная рекомендация.
