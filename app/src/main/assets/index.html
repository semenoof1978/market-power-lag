Автообновление цен

Цены Мосбиржи из открытого API приходят с задержкой около 15 минут. Котировку Совкомбанка приложение не видит и считает её как стоимость пая ±спред. Сигнал верен, только если цены продержатся до закрытия дня, по которому посчитают новую стоимость пая, и маркет-мейкер не сменит правила. Это калькулятор, а не рекомендация.
